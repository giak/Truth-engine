# DATA PARADISES — réservoirs publics sous-exploités

Le terme est une métaphore de réservoirs de données publics, pas une insinuation d'illégalité.

## France
- HATVP représentants d'intérêts : activités, dépenses, FTE, cibles, JSON.
- HATVP influence étrangère / ARGOS : mandants, liens, actions.
- Assemblée : voyages, groupes d'amitié, questions, amendements, votes, auditions.
- Sénat : auditions, colloques, groupes, amendements.
- Légifrance / Justice / CEDH : circulaires, jurisprudence, versions.
- RNA / JOAFE / INPI / comptes associatifs : entités et dirigeants.

## États-Unis
- IRS 990 / 990-PF : Schedule F, I, R, O ; financeurs et transferts.
- ProPublica Nonprofit Explorer comme index, puis fichiers IRS.

## Israël
- mr.gov.il : marchés publics, montants, fournisseurs, objets.
- Knesset : budgets, auditions, programmes de diplomatie publique.
- gov.il : appels à projets et rapports.
- Registre entreprises : entités / dirigeants.

## Union européenne
- Transparency Register.
- Commission/EEAS meeting transparency.
- Parlement européen : voyages, amendements, résolutions, questions.

## Leaks / archives
- EIC Israel Files.
- DDoSecrets Library of Leaks : corpus primaire du ministère israélien de la Justice selon EIC.
- Archives web / DNS / WHOIS pour les infrastructures techniques, jamais attribution unique.
