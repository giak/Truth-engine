# RENARD DELTA — INV-166

## Question bornée

Fermer, si une pièce publique accessible le permet, l'arête :

`ELNET Europe-Israel (580535672) -> mandat / sous-traitance / instruction -> ELNET France (531006237) -> organisation du colloque au Sénat du 10 novembre 2025`.

## Résultat

**NO_UPGRADE / RESPONSIBILITY_GAP PERSISTS.**

Le web public supplémentaire confirme au niveau agrégé :

- un financement israélien de 72 000 euros pour le colloque ELNET au Sénat ;
- la tenue de l'événement le 10 novembre 2025 ;
- la revendication par ELNET France d'être l'organisateur de l'événement ;
- des communications publiques parlant d'« ELNET » sans toujours distinguer les personnes morales.

Mais aucune pièce primaire publique inspectable n'a été trouvée qui ferme le pont entre les deux personnes morales :

- contrat de sous-traitance ;
- mandat ;
- facture inter-entités ;
- instruction ;
- convention d'organisation ;
- annexe de marché ;
- email authentifié ;
- document comptable affectant les 72 000 euros à ELNET France.

## Conséquence probatoire

Le résultat certifié d'INV-166 reste inchangé :

- `MFA israélien -> ELNET Europe-Israel -> opération du 10/11/2025` = **SUPPORTED / bounded by prior-certified procurement evidence** ;
- `ELNET France -> organisateur déclaré de l'événement` = **SUPPORTED** ;
- `ELNET Europe-Israel -> mandat/tasking d'ELNET France pour cet événement` = **UNRESOLVED / RESPONSIBILITY_GAP** ;
- `absence d'ELNET du registre ARGOS -> manquement` = **NOT ESTABLISHED** ;
- `financement ponctuel -> commandement général d'ELNET France` = **NOT ESTABLISHED**.

## Ce qui ferait changer le verdict

Réouvrir uniquement sur apparition d'une pièce primaire ou quasi-primaire : marché complet/annexe, convention, facture, mandat, email, compte analytique, déclaration officielle ou document administratif permettant d'identifier le donneur d'ordre, l'exécutant et le périmètre de l'action.

Une nouvelle collecte générique de mentions « ELNET » serait cumulative et ne fermerait pas l'arête juridique.
