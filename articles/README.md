## Notes

- Chaque dossier correspond à un sujet unique, avec ses versions et itérations.
- Les dossiers structurés (00-07) suivent le protocole d'enquête KERNEL.
- `misc/` contient des fichiers qui n'ont pas de dossier dédié (prompts visuels, assets).
- **0 fichier à la racine** — tout est rangé.
