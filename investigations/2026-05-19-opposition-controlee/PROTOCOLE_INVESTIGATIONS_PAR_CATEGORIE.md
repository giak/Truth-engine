# PROTOCOLE — INVESTIGATIONS PAR CATÉGORIES

**Date :** 2026-05-20
**Pipeline :** KERNEL v2.0 — Investigations batch par type
**Objet :** Protocole d'investigation systématique de l'écosystème "opposition contrôlée"

---

## §0 — PRINCIPE

Investiguer systématiquement toutes les figures de l'écosystème dissident français par **catégorie**, en suivant un **template unique** pour chaque investigation. Permet :
- Comparabilité des résultats entre catégories
- Détection de patterns transversaux (financements, liens, censures)
- Construction progressive du réseau complet
- Éviter les biais de confirmation par approche systématique

## §2 — TEMPLATE D'INVESTIGATION (UNIVERSEL)

Chaque investigation suit ce template :

```
# INVESTIGATION — [CATÉGORIE] : [NOM]

**Date :** YYYY-MM-DD
**Catégorie :** [Médias/Économistes/Politiques/Journalistes/Intellectuels]
**Complexité :** APEX (18/18)
**Pipeline :** KERNEL v2.0

---

## §0 — CONTEXTE
- Rôle dans l'écosystème
- Pourquoi cette figure est pertinente
- Liens avec investigations précédentes

## §1 — FAITS (sources primaires + mainstream + alternatif)

### Pôle A : Identité et parcours
- Formation, carrière, positions
- Sources : Wikipedia, LinkedIn, sites officiels

### Pôle B : Positions controversées
- Thèses défendues, propos marquants
- Sources : vidéos, articles, livres

### Pôle C : Sanctions/Censures
- Condamnations judiciaires
- Censures plateformes (YouTube, Twitter, etc.)
- Listes MIVILUDES/UNADFI/Conspiracy Watch
- Sources : jugements, rapports officiels

### Pôle D : Financement
- Modèle économique déclaré
- Financements identifiés (dons, subventions, investisseurs)
- Zones d'ombre financières
- Sources : bilans financiers, SIREN, registres

### Pôle E : Liens avec l'écosystème
- Apparitions sur d'autres médias alternatifs
- Soutiens réciproques
- Conflits avec d'autres figures
- Sources : vidéos croisées, articles

## §2 — CHAÎNES CAUSALES
- Chaîne 1 : [origine] → [action] → [conséquence]
- Chaîne 2 : ...

## §3 — ANALYSE CROISÉE
- Comparaison avec figures similaires
- Patterns communs
- Différences notables

## §4 — DIALECTIQUE
- ⟐🎓 Thèse (Mainstream)
- 🔥⟐̅ Antithèse (Contre-narratif)
- ◈◉○ Synthèse (Vérité forensique)

## §5 — GATE_CHECK
- Biais identifiés
- Ce qui reste incertain
- Verdict

## §6 — CONCLUSION
- Rôle dans le réseau
- Statut légal
- Financement
- Intégration au réseau global

## ANNEXE — Sources
```

## §5 — RÈGLES D'EXÉCUTION

1. **Batch par batch** : ne pas mélanger les catégories
2. **Priorité HAUTE d'abord** : dans chaque batch, traiter les HAUTE avant MOYENNE/BASSE
3. **Parallélisme** : lancer toutes les requêtes websearch en parallèle pour une figure
4. **Cross-check** : après chaque figure, vérifier les liens avec les figures déjà investiguées
5. **Synthèse par batch** : après chaque batch, produire une synthèse intermédiaire
6. **Synthèse finale** : après tous les batches, produire le réseau complet
