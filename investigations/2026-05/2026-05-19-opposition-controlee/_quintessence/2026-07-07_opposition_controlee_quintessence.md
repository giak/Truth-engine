## Mécanismes / chaînes causales

11 chaînes causales de profondeur 5 niveaux (§10 CHAÎNES DE CASCADE). Source §10 L339-L369.

### Chaîne 1 — Finance → Médias → Opinion → Vote [§10.L339-L369(estimé)]
```
Concentration médiatique (9 milliardaires)
  → Cadrage éditorial favorable statu quo
  → Opinion publique orientée
  → Vote cadre acceptable
  → Partis établis maintenus
  → Concentration médiatique inchangée
→ BOUCLE FERMÉE
```

### Chaîne 2 — Arcom → Temps de parole → Résultats électoraux [idem]
```
Critères équité Arcom (résultats passés)
  → Plus de temps pour partis établis
  → Meilleurs résultats électoraux
  → Encore plus de temps
→ CERCLE VICIEUX INSTITUTIONNEL
```

### Chaîne 3 — Algorithme → Visibilité → Polarisation → Engagement [idem]
```
Algorithmes amplifient certains contenus politiques
  → Modification attitudes partisanes (Science 2025 : 2 pts/semaine = 3 ans polarisation)
  → Polarisation accrue
  → Plus d'engagement
  → Algorithmes optimisés pour engagement
  → Amplification renforcée
→ BOUCLE D'AMPLIFICATION
```

### Chaîne 4 — Aide publique → Dépendance → Conformité [idem]
```
Partis reçoivent €65,4M aide publique (résultats électoraux)
  → Dépendance financière système
  → Conformité règles du jeu
  → Résultats électoraux suffisants
  → Aide publique maintenue
→ CAPTIVITÉ FINANCIÈRE
```

### Chaîne 5 — Pantouflage → Réseaux → Influence → Reproduction élites [idem]
```
Hauts fonctionnaires → secteur privé (postes rémunérés)
  → Réseaux d'influence croisés (CA, consulting, lobbying)
  → Influence sur politiques publiques
  → Avantages secteur privé
  → Recrutement hauts fonctionnaires
→ REPRODUCTION DES ÉLITES
```

### Chaîne 6 — Think tanks → Cadre intellectuel → Primaires → Candidat filtré [idem]
```
Terra Nova (30+ rapports 2008-2012)
  → Primaires ouvertes adoptées PS (2008-2009)
  → Primaire sélectionne candidat « primaire-compatible »
  → Hollande 2011 (système) bat Montebourg (radical)
  → Opposition interne neutralisée
→ FILTRAGE INTELLECTUEL
```

### Chaîne 7 — Sondages → Opinion fabriquée → Médias → Sondages [idem]
```
Instituts sondages (IFOP, Ipsos, Harris — ×40/50 ans)
  → Redressement statistique boîte noire
  → Médias publient intentions
  → Course de chevaux remplace fond
  → Commandes médias/partis/entreprises
  → Instituts financés par système
→ CERCLE VICIEUX OPINION
```

### Chaîne 8 — Clubs élites → Convergence → Opposition responsable → Pouvoir [idem]
