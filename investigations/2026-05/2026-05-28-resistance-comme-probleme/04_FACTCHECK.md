## §4.2 Vérifications détaillées

### D008 : Blast levées contestées
Source : Franc-Tireur + ModoPerandi
- Franc-Tireur est un média papier, pas un blog anonyme
- Le procès a eu lieu : Cour d'appel de Paris, Blast et Denis Robert déboutés
- **Statut : ✅ confirmé** (fait judiciaire documenté)

### D016 : Presse française par milliardaires
Source : Jacobin / Marc Endeweld
- Endeweld est un journaliste d'investigation réputé (a quitté Marianne pour censure)
- Les chiffres sont cohérents avec d'autres sources (Bolloré : Canal+, CNews, Europe 1 ; Křetínský : Marianne, Elle, etc.)
- **Statut : ✅ confirmé** (multiples sources concordantes)

### D018 : Twitter Files France
Source : Sud Radio
- Twitter Files (Matt Taibbi, 2022) n'a pas spécifiquement ciblé la France
- Les chiffres de "90% des requêtes sans lien terrorisme" viennent de Twitter/X Transparency Report
- **Statut : ⚠️ nuancer** — dire "selon Twitter Transparency Report, la France était le premier demandeur mondial de retraits"
