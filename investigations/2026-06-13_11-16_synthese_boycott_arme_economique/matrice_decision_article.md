## DIMENSION 4 — PROBLÈME DE CLASSE

C'est le gap le plus critique du corpus. Les deux articles (Éloge et V2) l'identifient sans le résoudre. Le traiter frontalement est risqué mais nécessaire.

| Option | Forces | Faiblesses | Score |
|--------|--------|------------|-------|
| **A. Reconnaître et passer** | Cohérent avec Éloge. Simple. Garde le focus. | Problème réel ignoré encore une fois. Incohérent avec le principe d'honnêteté (AGENTS.md §1 : priorité à la vérité). Les lecteurs qui voient le gap perdent confiance. | 3/10 |
| **B. Mettre au centre** | Honnête, original, utile. Seul moyen de résoudre la contradiction. Donne une profondeur rare. | Complique l'article. Peut le faire déraper vers un autre sujet. Risque de noyer le message principal. Demande une écriture précise. | **7/10** |
| **C. Esquiver** | Simple, focus, article plus court. | Gap critique non résolu. Contraire à AGENTS.md §1 (vérité). Les 3 enquêtes qui identifient ce gap (SAT, USA, V2) le font pour une raison : il est central. | 2/10 |

**Décision : B** — Le problème de classe devient le **§5** (après la pratique, avant la conclusion). Le placer avant la théorie cassait l'élan. Après la pratique, c'est un caveat honnête qui laisse la tension non résolue — plus puissant. Trois paragraphes maximum, pas de solution miracle (ce serait malhonnête).

### Architecture de l'article

```
§0  — Accroche : 3 lignes, reprend la question finale d'Éloge
§1  — Pont : 3 phrases résument Éloge + annonce le dépassement
      « Éloge montre le bouclier, voici le levier »
§2  — Théorie : le levier V2 (ICRG, spread, signal aux marchés)
      (cœur : comment le boycott agit sur la dette souveraine)
§3  — Preuve : les GJ comme validation expérimentale V1-sans-V2
      (preuve que la surface seule = V1 sans V2 = mort)
§4  — Pratique : les 5 piliers de l'infrastructure V2
      (circuits, trésorerie, juridique, numérique, production)
§5  — Caveat : le problème de classe
      (gap non résolu, caveat honnête après la pratique)
§6  — Bouclage : retour à Éloge + auto-critique + question ouverte
```
