# DOSSIER-SOURCE — Template de rédaction

**Date :** 2026-06-23
**Projet :** La Laisse — 64 enquêtes forensiques
**Usage :** Framework de distillation des APEX bruts en entrées publiables pour le dossier-source

---

## Principe

Chaque APEX (150-350 lignes, 15 symboles scorés, 10-20 faits atomiques) est distillé en une entrée standardisée de ~10-15 lignes. Objectif : le lecteur peut vérifier un score, comprendre le mécanisme d'inversion et identifier la source sans se noyer dans les données brutes du Truth Engine.

---

## Template d'entrée

```
## [Score Ω] — [Nom du secteur]

**Montant** : [X Md€/an] · **Mécanisme** : [niche/subvention/monopole/statut]
**Leurre** : Ce que le secteur dit être.
**Réalité** : Ce qu'il est vraiment.
**Fait clé** : [1 fait atomique, le plus percutant, sourcé]
**Verrou** : [1 ligne — chaîne causale : cause → mécanisme → conséquence → verrouillage]
**Ω** : Invisibilité X/10 · Confort X/10 · Visibilité X/10 · Précarité X/10
**Sources** : [réf précise, URL, rapport]
```

---

## Règles de rédaction

### 1. Score Ω
Tiré de la synthèse globale. Le score est le classement final.

### 2. Montant
Toujours en milliards d'euros par an (Md€/an). Si le montant est ponctuel, le préciser. Si le transfert est indirect (monopole, statut), l'estimer ou le qualifier.

### 3. Mécanisme
Une des catégories suivantes, utilisée telle quelle :
- `subvention directe` — argent public versé explicitement
- `niche fiscale` — renoncement à recouvrer de l'impôt
- `monopole` — exclusivité légale d'exercice
- `statut` — régime dérogatoire (emploi à vie, retraite anticipée)
- `contrat garanti` — prix ou marché garanti par l'État
- `taxe affectée` — prélèvement obligatoire fléché vers un secteur
- `garantie implicite` — passif conditionnel de l'État

### 4. Leurre / Réalité
Format asymétrique :
- Leurre = le discours public du secteur (entre guillemets)
- Réalité = le mécanisme réel, sans guillemets
- Les deux tiennent en une ligne chacun

### 5. Fait clé
Un seul fait atomique, le plus révélateur du pattern d'inversion. Doit inclure un chiffre et une source explicite. Si possible, citer le fait qui produit le plus de dissonance.

### 6. Ω (4 scores bruts)
Invisibilité, Confort, Visibilité, Précarité — chacun sur /10. Tirés de l'APEX correspondant.

### 7. Sources
Toujours une référence précise : nom du rapport, institution, année. Si URL disponible, la fournir. Jamais de source vague (« rapport parlementaire »).

### 8. Ton
- Neutre, factuel, journalistique
- Pas de commentaire moral — le lecteur tire ses propres conclusions
- La dissonance doit venir des faits, pas de la rhétorique

---

## Exemple

```
## 150 — Énergies renouvelables

**Montant** : 7,44 Md€/an · **Mécanisme** : subvention directe + contrat garanti
**Leurre** : « Transition climatique héroïque »
**Réalité** : Placement financier garanti par l'État sur 20 ans, dont les bénéfices vont à des fonds d'investissement internationaux
**Fait clé** : 87 Md€ d'engagements hors bilan de l'État fin 2024 pour des contrats ENR signés sur 20 ans — dette cachée que personne n'a votée (Cour des comptes, mars 2026)
**Ω** : Invisibilité 10/10 · Confort 10/10 · Visibilité 2/10 · Précarité 2/10
**Sources** : Cour des comptes, « Le soutien aux énergies renouvelables », mars 2026 ; CRE, « Charges de service public de l'énergie », prévisions 2025-2026
```
