## △ PRÉAMBULE — v2.4 NREF

◆ Protocole hérité v1.0→v2.3. 8 fils, 42 mécanismes, 10 stratégies.
◉ 5 piliers:
   1. Chaîne de preuve: chaque mécanisme → traceur vérifié (URL, citation directe, HEAD check)
  2. Contre-version sourcée: version officielle présentée + réfutée point par point
  3. Honneur cognitif: incertitudes, biais enquêteur, statut réel sources (glyphes)
  4. Archéologie des fils + Pelote de Laine: remontée jusqu'à acte fondateur (200+ ans)
  5. Contre-mesures opérationnelles: actions concrètes avec acteur, fenêtre, faisabilité, précédent

◆ Thèse centrale: Défaillances françaises = architecture systémique 200+ ans, maintenue par mécanismes homéostatiques transforment colère→carburant, résistance→maintenance, lucidité→fonction.

◇ Constats fondateurs: système produit défaillances silencieuses sans contre-réaction; sang contaminé 1984 a révélé 8 fils causaux remontant 1791; chaque fil = verrou neutralisant contre-pouvoir.

◇ Nouveaux constats v2.1: enquetes v2.0 sans sources verifiées (✦ sans HEAD check, URLs non citées); protocole disait QUOI pas COMMENT; Ultrathinking mentionné pas exécuté; enquete NREF sans sources = essai pas preuve.

◇ Nouveau constat v2.2: enquetes identifient M## mais ne remontent PAS les fils (RACINES = causes immédiates 0-3 ans); M11+M28+M05 invariant dans 5/5 sans explication construction; sans archéologie = photographie pas diagnostic.

◇ Nouveau constat v2.3: enquetes identifient mécanismes+racines mais pas QUOI FAIRE; RESISTANCE propose stratégies abstraites sans acteur/fenêtre; BIFURCATIONS disent "où" pas "quoi/qui"; sans contre-mesures = autopsie sans réanimation.

## △ PARTIE III: EXIGENCES NREF v2.1

### ◆ Principe
Enquête NREF = dossier de preuves structuré. Sources VÉRIFIÉES (URL, HEAD check, citation directe). Source non vérifiée = ❧.

### ⊙ Barème 12 exigences
| # | Exigence | Sanction si non respectée |
|---|----------|--------------------------|
| NREF-1 | M## dominant → traceur dans PREUVES | [HYPOTHÈSE] |
| NREF-2 | CONTRE_VERSION ≥ narrative + réfutation | [PLAIDOYER] |
| NREF-3 | INCERTITUDES ≥ fourchette + question | [CERTITUDE EXCESSIVE] |
| NREF-4 | BIAIS_ENQUÊTEUR ≥ parti-pris + angle | [ANGLE MORT NON DÉCLARÉ] |
| NREF-5 | ACTIVATION ≥ 1 date par M## dominant | [UTILISATION TRANSVERSALE IMPOSSIBLE] |
| NREF-6 | RÉPLICATION ≥ prédiction + condition réfutation | [NON FALSIFIABLE] |
| NREF-7 | Chaque chiffre → source dans fourchettes | [NON VÉRIFIÉ] |
| NREF-8 | Fiche > 200 lignes | [SURVOL] |
| NREF-9 | Chaque source → source_url vérifiée HEAD | [SOURCES NON VÉRIFIÉES] |
| NREF-10 | Contre-version → source réelle URL+auteur | [CONTRE-VERSION NON SOURCÉE] |
| NREF-11 | Chaque fil actif → archéo complète avec Pelote | [PELOTE NON DÉFILÉE], max NREF-C |
| NREF-12 | ≥2 contre-mesures (1 PENDANT/APRES + 1 PRÉVENTIF) | [AUTOPSIE SANS REMÈDE] |

### ⊙ Échelle robustesse v2.3
A: 12/12 → preuve. B: 1-8(+9,10) → solide. C: 1-5 → partiel. D: 1-3 → essai. E: 0-1 → refusée.

### ◆ Règle chaîne de preuve
◉ Tout M## dominant → entrée PREUVES lie_a:[M##]. Si sans traceur → [HYPOTHÈSE].
◉ ✦ = HEAD 200 OK + head_check_date. ✧ = source secondaire URL vérifiée. ⁅ = lien mort. ❧ = pas d'URL.
◉ Si >50% ❧ → max NREF-C.

## △ MÉTHODE PELOTE DE LAINE v2.4

### ◆ Principe
Remède au biais de disponibilité cognitive. Force remontée jusqu'à racine fondatrice.

### ◆ Algorithme 5 questions récursives
◉ Exécuter dans l'ordre, sans sauter:
1. **T-1** (0-10 ans): événement/loi/institution la plus récente ayant rendu ce mécanisme possible?
2. **T-2** (10-50 ans): qu'est-ce qui a rendu T-1 possible?
3. **T-3** (50+ ans): qu'est-ce qui a rendu T-2 possible?
4. **Acte fondateur**: racine ultime du fil?
5. **Vérification récursive**: acte fondateur a-t-il un antécédent? Si oui → retour Q4.

### ◆ Règle d'arrêt
⊙ 4 catégories:
- RACINE ANCIENNE (avant 1789)
- RACINE FONDATRICE (1789-1815)
- RACINE CONSTITUTIVE (constitution/traité)
- RACINE CULTURELLE (pratique/jurisprudence)
◉ Si aucun acte antérieur à 1800 → [PROFONDEUR INSUFFISANTE] → relancer

### ◆ Exemple Fil B (ARCOM)
T-1: ARCOM 2021 ← HADOPI 2009 → T-2: LCEN 2004 ← ORTF 1964 → T-3: Nationalisations 1945 → Acte: Le Chapelier 1791 [RACINE FONDATRICE]
→ Chaîne: 1791→1811→1945→1964→2004→2009→2021→2024→2026

### ◆ Intégration workflow
1.5.0 Pelote → 1.5.1 Référentiel → 1.5.2 HEAD check → 1.5.3 Chaîne causale

### ⊙ Check-list profondeur (6 questions)
□ Acte naissance antérieur 1800? Sinon [PROFONDEUR INSUFFISANTE]
□ Saut >30 ans non expliqué? → RENFORT MANQUANT
□ Tous renforcements liés M##? Sinon [HYPOTHÈSE]
□ Racine pré-révolutionnaire? → [RACINE ANCIENNE]
□ Bifurcation possible? Sinon verrouillage robuste
□ Autres enquêtes même acte? Sinon INCOHÉRENCE TRANSVERSE

### ◆ Candidats auto-référents (Fil I, J, K...)
Quand acte naissance = événement enquêté (circularité douce).
◉ a) Chaîne causale OBLIGATOIRE partant d'avant l'événement (≥1 verrou préalable documenté, seuil 10 ans indicatif)
◉ b) Double marquage [CANDIDAT EN TEST]
◉ c) ≥1 contre-exemple documenté
◉ d) Limitation dans BIAIS_ENQUÊTEUR

→ Exemple Fil I (Vassalité monétaire, Maastricht 1992): chaîne causale 1983 virage rigueur → 1992 Maastricht → confirmée par renforcements 1999/2005/2012/2020. Contre-exemple: Danemark opt-out 1992, garde couronne. Marquage [CANDIDAT EN TEST]. Biais déclaré: "acte de naissance = événement enquêté — circularité douce".

### ◆ Sanction
Sans REMONTÉE_DES_FILS ou Pelote non exécutée → max NREF-C

## △ PARTIE X: CONTRE-MESURES OPÉRATIONNELLES v2.3

### ◆ Principe
5e pilier. Pont diagnostic→action. Les enquêtes identifient mécanismes+racines mais pas QUOI FAIRE.

### ◆ 3 temporalités
| Temporalité | Rôle |
|-------------|------|
| PRÉVENTIF | Avant bascule pour empêcher |
| PENDANT | Pendant bascule pour limiter dégâts |
| APRÈS | Après bascule pour empêcher récurrence |

### ◆ 3 niveaux acteurs
| Niveau | Acteur type | Coût |
|--------|-------------|------|
| MICRO | Citoyen, journaliste, lanceur | Faible |
| MESO | Association, syndicat, média | Moyen |
| MACRO | Gouvernement, Parlement | Élevé |

### ◆ Structure CONTRE_MESURES (YAML)
◉ ≥2 actions (1 PREVENTIF + 1 PENDANT/APRES):
temporalité + cible_fil + cible_M## + action_concrète + acteur + fenêtre + faisabilité + coût + précédent_historique + source_preuve + non_faite_parce_que
⟐ Verrous + apprentissages

### ◆ 5 règles CM
◉ Opérationnelle (acte vérifiable + acteur nommé)
◉ Précédent historique vérifié
◉ 3 temporalités obligatoires
◆ 3 niveaux acteurs recommandés
◆ Faisabilité faible = documentée quand même

### ◆ Sanction
Sans CONTRE_MESURES → max NREF-B
