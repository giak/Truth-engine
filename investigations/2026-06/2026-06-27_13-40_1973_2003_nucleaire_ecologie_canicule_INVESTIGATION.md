# INVESTIGATION APEX — Verrou nucléaire et naissance de l'écologie (1973-2003)

## §0 MÉTA
**Série** : 4/5 — 1973 → Premier choc pétrolier → Tout-nucléaire → Canicule 2003

## §1 RÉSUMÉ
1973-2003 : 30 ans qui verrouillent la France dans deux directions contradictoires :
1. **1974** : Plan Messmer → 13 réacteurs nucléaires en 5 ans. Décision prise en 3 mois, sans débat parlementaire, sans consultation citoyenne. La France devient le pays le plus nucléarisé au monde. L'électricité abondante et « décarbonée » (hors déchets) légitime la consommation : chauffage électrique, puis clim réversible.
2. **1980s-1990s** : Émergence de l'écologie politique française (Les Verts, 1984). Premières lois sur la qualité de l'air, l'eau, les déchets. Mais l'écologie française reste faible, divisée, incapable de remettre en cause le nucléaire.
3. **2003** : Canicule → 14 000 morts. L'AC devient une question de santé publique. Le verrou saute : la clim n'est plus un luxe — c'est une nécessité médicale.

Le paradoxe : le programme nucléaire a créé l'électricité abondante qui rend la clim « propre » en France (94% décarboné) — mais il a aussi empêché toute réflexion sur la sobriété.

## §3 CHAÎNES CAUSALES

### Chaîne A : Le verrou nucléaire → l'AC comme sous-produit (1974-2026)
```
Oct 1973: Choc pétrolier → panique nationale
→ Mars 1974: Plan Messmer (13 réacteurs, 1 tous les 4 mois) — décision sans débat
→ 1980s: Surchauffe nucléaire → EDF doit écouler les kWh → chauffe électrique subventionné
→ 1990s: Première clim réversible (pompe à chaleur) → utilise l'électricité nucléaire
→ 2000s: Le chauffage électrique + clim devient la norme dans le neuf
→ 2026: 94% électricité décarbonée → argument massue : « la clim nucléaire est propre »
Endpoint: Le choix de 1974 (urgence pétrolière) est l'argument de 2026 (la clim est verte).
```

### Chaîne B : L'écologie française divisée → impuissance climatique (1984-2026)
```
1984: Les Verts créés → mais divisés (radicaux vs réalistes)
→ 1990s: Voynet, Mamère, Cochet → jamais assez forts pour gouverner
→ 2002: Jospin éliminé → l'écologie ne perce pas
→ 2007: Grenelle de l'Environnement → promesses non tenues
→ 2017: Hulot nommé → démission 2018 → l'écologie incapable de réforme structurelle
→ 2026: Barbut « horrifiée » mais impuissante → l'écologie française n'a jamais eu le pouvoir
Endpoint: Depuis 1984, l'écologie française parle mais ne décide pas.
```
