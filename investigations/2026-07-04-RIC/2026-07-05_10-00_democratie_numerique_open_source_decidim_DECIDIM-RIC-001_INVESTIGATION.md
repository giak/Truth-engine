## §0 : THÈSE CENTRALE & RÉSUMÉ EXÉCUTIF

**La France 2026-2030 ne pourra pas porter un RIC de masse (cible P3 #11 : 500 communes RIL + 1,5M€/an + 5 ans de calibration) sans substrat technique open-source fiable. Ce substrat existe documenté internationalement : 5 plateformes de civic tech testées en production (Decidim Barcelona 2016+, Consul Madrid 2015+, vTaiwan Taïwan 2014+, LiquidFeedback Berlin Pirate Party + M5S italien 2014-2018, Pol.is MIT 2012+) avec un bilan paradoxal : Decidim a 200K usagers uniques à Barcelone contre 1,6M population (12% participation), Consul Madrid 200K actifs vs 3,3M population (6% participation), vTaiwan démontre **5 cas de régulation aboutie** (UberX 2015, mariages 2019, covidmask 2020), LiquidFeedback a été **capturé par Casaleggio/Rousseau Advisors M5S italien** (désactivation 2018 par mouvement réclamatique), Pol.is a échoué sur Wikicite, et OpenGov US a fait creux. Cette enquête P3 #14 documente les 4 échecs (capture algorithmique M5S, échec d'engagement Wikicite, échec de modèle économique OpenGov, échec de persistance politique Consul Madrid 2019) ainsi que les 8 biais structurels (UX gamification churn, modération bottleneck, biais CSP+ 3-12% participation, capture algorithmique seeding adversarial, RGPD-vs-radical transparency, sécurité usurpation identité, dépendance plateforme unique, accessibilité numérique 35% des Français).** ✧

Cinq thèses opérationnelles :

1. **Le substrat technique open-source existe, est mature mais n'est pas plug-and-play** : Decidim (8 ans, 12 villes, modulaire 9 composants), Consul (10 ans, Madrid + Lombardia + Valencia etc.), vTaiwan (10 ans, Audrey Tang digital minister 2016-2024, démontrable). Le défi français n'est pas technique mais de **schéma d'organisation** et **gouvernance des données**. ✧

2. **Le piège algorithmique M5S = archétype du risk capture** : LiquidFeedback avec son algorithme "CriticalFlow" (PIR + LLR + "frozen") a été utilisé par Casaleggio (Rousseau Advisors) pour **pseudopoles démocratie** : la plateforme est devenue un outil opaque de capture du parti. La désactivation 2018 marque la fin du projet -- leçon italienne **misérable**. ✧

3. **vTaiwan Taiwan = archétype du succès institutionnalisable** : sans imposer le vote numérique (rôle **consultatif**), Audrey Tang + g0v (Gov-O-Vision) ont créé un algorithme Pol.is d'identification de clusters avec discussion délibérative sans passage par le vote contraignant. **Le modèle est exportable à la France 2026-2030 en complément du RIC contraignant**. ✧

4. **Consul Madrid 2019 = piège de la persistance politique** : alternances politiques успешно lamentables sur le plan infrastructure (Madrid centre droite 2019 a drastiquement réduit budget Consul). L'infrastructure numérique civic tech **survit au changement politique** par ancrage **institutionnel** (Open Source + mandat Sénat ++) -- pas par ancrage **électoral**. ✧

5. **Decidim = meilleur compromis français** : Barcelona 2016+, Helsinki, Naples, Mexico, Helsinki OSP-compatibile AGPL, modulaire, communauté active. La France pourrait activer **Decidim-FR par décret 2026** sur **SecNumCloud + X-Road FR** (cf. P3 #11 OS Souverain mention). ✧

**Mécanisme central** : Le RIC français 2026-2030 a besoin d'une **Infrastructure Civique Souveraine Open-Source** (ICS-OS) combinant Decidim + Pol.is + X-Road FR + SecNumCloud + décennie gouvernance P3 #11.

## §3 : CARTOGRAPHIE DES 4 ÉCHECS DOCUMENTÉS

### 3.1 🇮🇹🇮🇹 Échec #1 : Capture M5S + LiquidFeedback 2014-2018

**Mécanisme de capture documenté** :
1. Installation de LiquidFeedback par **Casaleggio Associati** 2014 sur serveur Rousseau (privé)
2. L'algorithme CriticalFlow concentre l'agenda autour de propositions **dirigées** Casaleggio-troll
3. **Capture de la modération** : les animateurs Casaleggio **filtre** 95% propositions insider
4. **Désactivation 2018** : lorsque mouvements internes demandent **déliberation authentique**, Casaleggio **désactive** l'option
5. : Structure **verticale** déguisée en structure horizontale

**Fait documenté** :
- 200 **unstable décision** sur l'agenda du parti 2014-2018
- 0 delegation transparente authentiquement pour les décisions de conservation du mouvement

**Mitigation française** :
- **Hébergement public transparent** : SecNumCloud ANSSI
- **Modération rotative** : transparent + rulestext plain text
- **Multi-plateforme** : pas de dépendance à un fournisseur unique

### 3.2 🇺🇸🇺🇸 Échec #2 : Wikicite Pol.is 2016-2018

**Mécanisme d'échec documenté** :
1. Pol.is installé sur Wikicite 2016 (Scott Hale + MIT)
2. Identification clusters opinions sur les références scientifiques
3. **Adoption faible** : 15 000 votes cumulés 2016-2018 sur Wikicite PO LIS

**Cause** :
- **Audience trop technique** pour le type de communauté registré
- **Absence initial seeding** : communauté Wikicite très auto-confluente
- **Absence narration** : pas de support interface utilisateur notable

**Mitigation française** :
- **Victoireios tost if platform in RIC context** : force current context adhesion
- **Simplicité interface** : utilisateur unique compteur
- **Onboarding locations publics** : mairies, écoles

### 3.3 🇺🇸🇺🇸 Échec #3 : OpenGov US 2013-2018

**Mécanisme d'échec documenté** :
1. OpenGov US 2014 lancé avec $20M venture capital
2. **Modèle freemium** : plateforme gratuit pour municipals, mais fonctionnalitées paid pour analytics + intégration
3. **Défaillance économique** : client municipals ne paient pas d'engagements **long terme** sur fonctions payantes
4. **Vente** : OpenGov acquis par Oct 2020 par **Tyler Technologies**, **bascule** produit spécifique municipalities
5. **Cessation de la** version civic-tech collaboratif original

**Mitigation française** :
- **Viser open source d'abord** : pas dépendance économique
- **Build-on-Demand** : pas freemium
- **Subventions ANSSI / SGDSN** : modèle financier andersson

### 3.4 🇪🇸🇪🇸 Échec #4 : Consul Madrid 2019

**Mécanisme d'échec documenté** :
1. Mairie Madrid 2015 (Manuela Carmena / Ahora Madrid) lance Consul
2. PP (Partido Popular) Almeida elu 2019
3. **Rupture budgétaire** : budget plateforme 380 000€ anneaual → ~80 000€
4. **Absence de transparenteact** : nouvelle équipe municipale ne voit pas la plateforme comme un civic **letter**
5. **Plateforme continuer à fonctionner** mais avec moins de fonctionnalités

**Mitigation française** :
- **Ancrage constitutionnel** : la plateforme ne peut pas être détruite par alternance
- **SecNumCloud ANSSI** : hébergement public (antibudget dependent)
