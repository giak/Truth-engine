## 6. Mécanismes / chaînes causales

Quatre mécanismes PELOTE à profondeur 4/4.

### M1 : Anonymat administratif comme exception française
**Type verrou :** STRUCTUREL ; **cadence :** générationnel
- L1 : CC publie décision sans rapporteur (RIP ADP 2019-1, RIP Climat 2024-3) : F-HFB02
- L2 : Bundesverfassungsgericht publie rapporteur dans TOUTES ses décisions
- L3 : Règlement intérieur CC pourrait être amendé sans révision constitutionnelle
- L4 : **Cause racine** : tradition administrative « Ancien Régime » (corps d'État protecteur) : Blanchard, Vie des Idées 2024

**Boucle :** Tradition corps d'État → règlement intérieur non modifié par inertie → rapporteur anonyme → aucune accountability → HF verrouillent sans coût politique → verrou se perpétue

### M2 : Pantouflage post-fonction
**Type verrou :** CONFLIT-D'INTÉRÊTS ; **cadence :** pluriannuel (carrière)
- L1 : Tous anciens SG CC, présidents CE se recyclent dans le privé post-fonction : Rapports publics CE
- L2 : Pantouflage crée **conflit d'intérêts permanent** : HF qui ont verrouillé RIC publiquement ensuite聘 dans groupes qui veulent maintenir verrou : L'Harmattan 2024, thèse Boiteau ⇒
- L3 : Pantouflage alimente réseaux d'influence pesant sur nominations futures : Patronage 2024, Sciences Po
- L4 : **Cause racine** : fonction publique française ne dispose pas mécanisme anti-pantouflage strict (HATVP dispose de simples déclarations) : Loi 2016-483 déontologue

**Boucle :** Pas contrôle pantouflage → HF bloquent institution contre leur propre intérêt post-fonction → recyclage garde alignement → verrou structurel renforcé.

### M3 : Chaîne d'opacité procédurale sur 4 étages
**Type verrou :** PROCÉDURAL ; **cadence :** dossier-par-dossier
- L1 : CC saisine → rapporteur → projet décision → vote → publication : Recueil CE 2024
- L2 : CE Section Intérieur rédige avis sur projets textes : Rapports annuels CE
- L3 : SGG mémoire en défense pour le gouvernement : Memoranda SGG (inaccessibles public)
- L4 : Commission Lois enterrement en discussion interne, pas en hémicycle : Comptes-rendus

**Boucle :** 4 étages opacité → décisions collectives anonymes → aucun responsable unique → verrouillage institutionnel impersonnel → exactement la thèse P0 #4 M3.

### M4 : Absence de transparence académique
**Type verrou :** DOCTRINAL ACADÉMIQUE ; **cadence :** générationnel
- L1 : Peu de thèses/articles académiques sur rapporteurs CC : HAL, Cairn
- L2 : Constitutionnalistes français respectent anonymat comme « réserve institutionnelle » : Chagnollaud, Fatin-Rouge Stefanini 2024
- L3 : Comparatistes étrangers (Allemagne, Italie, Espagne) notent exception sans la critiquer frontalement : Politeia (Rome)
- L4 : **Cause racine** : tradition d'auto-discipline constitutionnelle vis-à-vis de l'institution (analogie « robe » du magistrat)

**Boucle :** Constitutionnalistes français respectent anonymat → pas études critiques → exception non-documentée → verrou normatif académique renforce verrou opérationnel.

### Tissage
```
M1 (anonymat administratif) protège M3 (chaîne d'opacité)
M2 (pantouflage) protège M1 (anonymat par recyclage structurel)
M4 (transparence académique) protège M1 (doctrine respecte opacité)
```
