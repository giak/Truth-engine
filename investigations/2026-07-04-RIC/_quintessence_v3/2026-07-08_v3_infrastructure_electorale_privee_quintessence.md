## 6. Mécanismes / chaînes causales (4 + 1 écarté en §9)

**M1. Absence de marché vote politique = absence de produit industriel** (M1 §8 source)
Le marché politique français impose l'AGENT public en matière électorale ; les industriels n'ont pas de mandat pour nourrir ballot. Boucle : Constitution 1958 maintient vote ballot-papier → pas de marché vote électronique politique → pas de produit → pas de demande → Constitution inchangée. Cause racine : Constitution 1958 ne conçoit pas le vote autrement que matérielle (art. 3). [§8 source:L291-296 (estimé)]

**M2. Doctrine ANSSI/CNIL restrictive = autoprotection de la filière existante** (M2 §8 source)
Doctrine CNIL avril 2026 impose code source public + expertise indépendante ; aucune société française ne satisfait les deux critères. Effort industriel (25M€ pour développer vote électronique conforme) pharaonique. Boucle : doctrine restrictive → contrainte industrielle → marché vide → pas d'innovation → doctrine inchangée. Cause racine : l'ANSSI est un petit service <250 personnes, son agenda de protection est stimulant par principe. [§8 source:L298-303 (estimé)]

**M3. Confiance républicaine dans le ballot papier = tradition inspirante** (M3 §8 source)
Loi 2019-528 "confiance dans la vie politique" interdit le vote électronique politique. Tradition républicaine historique : tout ce qui touche au vote doit être "vérifiable par tous". Boucle : tradition d'expéditeur d'absolutisme → vote ballot-papier = contrôle populaire → toute innovation numérique suspecte → vote inchangé. Cause racine : la Révolution française a vengé le vote parèse par la desconfiance des institutions. [§8 source:L305-310 (estimé)]

**M4. Réticence industrielle des acteurs français** (M4 §8 source)
Docaposte ne présente que le segment CSE ; IN Groupe offre titres sécurisés pas vote ; Atos a délaissé secteur vote numérique. Cause racine : marché politique français impose l'AGENT public en matière électorale, industriels n'ont pas mandat. Boucle : mandat électoral ∈ État → industriels n'ont pas mandat → industriels n'investissent pas → marché industriel ne naît pas → vote politique reste ballot. [§8 source:L312-317 (estimé)]

### Conclusion opérationnelle

**Trois conclusions opérationnelles** :

1. **L'infrastructure électorale privée française n'est pas le verrou anti-RIC maximum ; le verrou actuel est anti-RIC numérique.** L'interdiction du vote électronique politique n'est pas idéologique mais industrielle : le secteur privé français (Docaposte / IN Groupe / Outscale) n'a pas développé de plateforme de vote politique conforme aux normes ANSSI. **Le verrou est dans l'absence de marché** : pas dans l'opposition explicite au RIC.

2. **Le coût comparé rend le RIC numérique 90% inférieur au RIC physique** (80-150M€ vs 380M€-1Md€). Économie potentielle 400-800M€ pour un RIC touchant 50M d'électeurs. Pourtant, le ministère de l'Intérieur a fait le choix de ne pas sous-traiter le vote à un acteur privé souverain (choix maintenu depuis 2019), préférant l'absence d'investissement dans une chaîne nationale.

3. **Le verrou réel est anti-réforme chez les décideurs politiques, pas chez les industriels.** L'asymétrie de mort §6.4 montre qu'aucun acteur industriel ne meurt significativement d'un RIC numérique : tous y gagnent ou y sont neutres. Le Manque Structurel (manque d'acteur industriel) prime sur la thèse du Verrou politique (forces anti-RIC assumées).
