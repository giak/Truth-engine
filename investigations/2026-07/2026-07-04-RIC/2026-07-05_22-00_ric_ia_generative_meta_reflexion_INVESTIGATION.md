## §5 : ARCHITECTURE TECHNIQUE

**Architecture GPT-4 (OpenAI)** :
- Modèle transformeur dense
- ~1.76T paramètres (estimation)
- Contexte 128K tokens
- Multimodal (texte + image)

**Architecture Claude 3 (Anthropic)** :
- Modèle transformeur dense
- Opus (le plus puissant) + Sonnet (intermédiaire) + Haiku (le plus léger)
- Constitutionnal AI (intégration feedback utilisateurs) + safety constitution

**Architecture Mixtral 8x7B (Mistral)** :
- Mixture of Experts (MoE) : 8 experts de 7B chacun, ~13B actifs par token
- Open-weights (Apache 2.0)

**Architecture LLaMA 3.1 (Meta)** :
- 405B paramètres
- English-majoring + multilingual
- Commercialisable chez Meta avec restrictions

**Architecture DeepSeek-R1** :
- MoE, 671B paramètres, ~37B actifs
- Open-source, performance équivalente OpenAI o1 sur benchmarks mathématiques

**EU AI Act (04-2024)** :
- Article 3 (Risques)
- Classification : inacceptable / haut / limité / minimal
- Article 5 (interdits) : Identification biométrique, social scoring
- Article 6 (haut risque) : infrastructure critique, education, emploi
- Application graduelle : 2/2025 (interdits), 8/2025 (haut risque), 2027 (général)

**Bletchley Declaration (11/2023)** :
- 28 pays signataires (US, UK, EU, France, China, Germany, Italy, India, Canada, Australie, etc.)
- Accent sur risques "frontier AI"
- Pas d'engagement contraignant ; déclaration soft law

## §7 : MENSONGES ET DIVERGENCES IDENTIFIÉS

**Mensonge n°1 (rumeur panique)** : "ChatGPT a supprimé des emplois de journalistes". Réalité : les LLM sont complémentaires, pas substituts ; les professions d'enquête changent.

**Mensonge n°2 (public marketing)** : "Les LLM sont neutres". Réalité : tous les LLM sont entraînés sur des corpus qui biaisent ; OpenAI/Anthropic/Mistral ont des chartes de sécurité mais avec biais résiduels.

**Mensonge n°3 (bruit dystopique)** : "L'IA va rendre impossible la vérité politique". Réalité : l'IA augmente la production de contenu relatif mais la vérification humaine reste nécessaire.

**Mensonge n°4 (asymétrie de visibilité)** : "L'IA est régulée strictement". Réalité : les LLM ne sont pas régulés hors EU AI Act (application 2026+), et ce n'est pas rétroactif sur les modèles existants.

**Mensonge n°5 (mauvaise foi pro-IA)** : "L'IA est un outil démocratique". Réalité : démoctatique selon le déploiement : ouverte + auditable → démocrate ; fermée + industrielle → oligopolistique.

## §14 : CONCLUSION

L'IA générative (LLM) est un **double tranchant** pour le RIC et la démocratie directe : à la fois outil facilitant l'audit citoyen, et vecteur de risque (deepfakes, désinformation synthétique, agents LLM sur-conduits). La méta-réflexion s'impose : ce dossier est produit par un système piloté par LLM lui-même.

**Trois conclusions opérationnelles** :

1. **Le marché LLM est oligopolistique** : OpenAI / Anthropic (US), Mistral (EU), Meta (US), DeepSeek (Chine) dominent. Pas de pluralité effective, même si l'open-weights atténue.

2. **La régulation européenne (EU AI Act) est pionnière**, adoptée 04/2024 et applicable 2025-2027. Les LLM sont classifiés par risque ; les applications politiques sensibles tombent en "risque limité" ou "haut risque" selon usage.
