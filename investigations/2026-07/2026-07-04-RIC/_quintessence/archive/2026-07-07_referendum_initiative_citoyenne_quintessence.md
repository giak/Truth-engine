## 5. Mécanismes / chaînes causales

3 mécanismes de profondeur 5 niveaux (§6 Causalité PELLOTE).

### M1 : Architecture verrouillée de 1958 (chaîne descendante) [§6.1:L237-L246]

```
Constitution 1958 (conçue pour De Gaulle, contre le parlementarisme)
  → Art. 11 & 89 : initiative populaire = zéro (₀)
  → Domaine réglementaire élargi (art. 37)
  → 49.3 : passage en force systématique
  → Conseil constitutionnel : gardien de l'orthodoxie 58
  → Aucun droit d'initiative citoyenne constitutionnelle
→ LE RIC SERAIT UNE RÉVISION IMPLICITE DE L'ARCHITECTURE
```

**Diagnostic :** Le RIC n'est pas un ajout à la Constitution : c'est une rupture avec son ADN. 1958 a été pensée pour concentrer le pouvoir, pas pour le diffuser.

### M2 : Capture oligarchique (chaîne horizontale) [§6.2:L250-L256]

```
Financement privé des partis
  → Dépendance aux donateurs (entreprises, grandes fortunes)
  → Déconnexion des intérêts populaires
  → Cartel législatif : les partis s'entendent pour ne pas toucher aux règles du jeu
  → Verrouillage de l'agenda parlementaire (conférence des présidents)
  → Exclusion des propositions citoyennes
→ LE RIC ROMPT LE MONOPOLE LÉGISLATIF DES PARTIS
```

**Diagnostic :** Les partis vivent du monopole de la représentation. Tout mécanisme qui contourne ce monopole (RIC) est une menace existentielle.

### M3 : Dogme européen (chaîne verticale) [§6.3:L260-L266]

```
Traités européens (Maastricht 1992, Lisbonne 2007)
  → Compétences exclusives UE (monnaie, commerce, concurrence)
  → Pacte de stabilité (3% déficit, 60% dette)
  → Finances publiques verrouillées par le droit européen
  → Un RIC sur une question budgétaire serait contraire aux traités
  → Mécanisme correctif : primauté du droit européen (arrêt Costa/ENEL, 1964)
→ LE RIC SUR LES FINANCES PUBLIQUES SERAIT INAPPLICABLE SANS SORTIR DE L'UE
```

**Diagnostic :** L'Europe érige en dogme l'intangibilité des règles budgétaires. Un RIC qui abrogerait une loi budgétaire violerait le droit européen : conflit de normes insoluble sans une révision des traités (unanimité, procédure impossible).
