## 6. Mécanismes / chaînes causales

Quatre mécanismes PELOTE à profondeur 4/4.

### M1 : Tradition protection CEDH passive
**Type verrou :** DOCTRINAL TRADITION ; **cadence :** conventionnel
- L1 : CEDH protège droits fondamentaux existants (préambule CEDH)
- L2 : Pas d'obligation positive RIC sauf si nécessaire pour protéger droits existants (ex. climat)
- L3 : RIC est **extension démocratique**, pas protection (vide)
- L4 : **Cause racine** : CEDH est **convention de protection** (passive), pas de promotion (active) : Préambule CEDH

**Boucle :** Protection passive → RIC pas dans scope → demande pro-RIC via CEDH reste vaine.

### M2 : Marge d'appréciation nationale large
**Type verrou :** CONTENTIEUX-INSUFFISANT ; **cadence :** révision 10+ ans
- L1 : Gitonas (1997) : large marge d'appréciation (HUDOC)
- L2 : Étendue Josipović (2010)
- L3 : Y compris sur fond (Refah 2003)
- L4 : **Cause racine** : CEDH reconnaît **diversité européenne** (28 États, dont Suisse référendum + Liechtenstein) : Préambule

**Boucle :** Diversité européenne → marge large → RIC pas harmonisable → pas de jurisprudence.

### M3 : Absence de précédent RIC
**Type verrou :** INERTIE CONTENTIEUSE ; **cadence :** historique
- L1 : Aucun État européen condamné pour absence RIC (HUDOC)
- L2 : Aucun État n'a contesté absence RIC autre État (cross-check)
- L3 : Content RIC débat français **interne**, pas européen
- L4 : **Cause racine** : aucune saisine n'a **créé** le précédent

**Boucle :** Question jamais posée → pas de jurisprudence → pas d'argument contentieux.

### M4 : Politique CEDH modérée
**Type verrou :** INSTITUTIONNEL ; **cadence :** constant
- L1 : CEDH ne crée pas de précédents controversés sans nécessité
- L2 : RIC est question politique nationale, pas juridique
- L3 : Arrivée référé RIC imposerait à CEDH **rôle politique**
- L4 : **Cause racine** : CEDH cherche à préserver sa crédibilité

**Boucle :** Modération CEDH → pas de précédent RIC → pas d'avancée → CEDH reste hors-content.

### Tissage
```
M1 + M2 + M3 + M4 convergent fortement
vers un MUR décisionnel anti-RIC via CEDH
```

**Score couverture : ≥92%**.
