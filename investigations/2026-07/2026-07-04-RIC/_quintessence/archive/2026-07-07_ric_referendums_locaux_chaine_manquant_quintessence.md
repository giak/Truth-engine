### 2.2 Distinction juridique référendum vs consultation vs pétition

| F-ref | Trace source | Faits atomiques |
|-------|--------------|-----------------|
| F-LOC06 | [§2.2:L36(estimé)] | **Référendum local décisionnel** : initiative conseil municipal/départemental/régional ; effet décision s'impose ; quorum ≥50% inscrits 1er tour (sinon consultation indicative) ; restriction : ne peut porter sur matières domaniales, fiscales, statutaires ou relatives au personnel |
| F-LOC07 | [§2.2:L42(estimé)] | **Consultation locale** : initiative conseil municipal uniquement ; effet avis indicatif (exécutif non lié) ; quorum aucun ; élasticité maximale (peut porter sur tout sujet) |
| F-LOC08 | [§2.2:L48(estimé)] | **Droit de pétition (art. L1112-16)** : initiative citoyens (1/10e des inscrits pour communes >50 000 hab ; 1/5e pour communes plus petites) ; le conseil municipal a 1 an pour répondre mais peut décider de l'organisation ou non d'un RIL ; effet aucun si le conseil refuse |
| F-LOC09 | [§2.3:L56(estimé)] | **Limites structurelles** : exécutif local reste maître de l'agenda (préfet peut s'opposer pour motif d'ordre public art. L1112-5) ; référendum décisionnel ne peut porter sur impôts ; ne peut réviser Constitution (art. 89 seul) ; pas d'effet hiérarchique sur droit supérieur |

## 6. Mécanismes / chaînes causales (PELOTE 4 mécanismes)

### M1 : Verrou préfectoral (art. L1112-5) ✧

| Niveau | Trace | Description |
|--------|-------|-------------|
| L1 | F-LOC28 B1 | Préfet peut bloquer RIL « pour motif d'ordre public » (art. L1112-5) |
| L2 | F-LOC28 B2 | Préfet est Haut Fonctionnaire issu de la culture centralisatrice (cf. P3 #1 HFB) |
| L3 | F-LOC28 B3 | En pratique, les préfets s'opposent ⟨informellement⟩ en amont (audition Sénat 2018) |
| L4 | F-LOC38 | Cause racine : Constitution 1958 « administration territoriale » ⇒ préfet garant du respect de l'ordre public central |

**Boucle M1** : préfet verrouille → maire prudent → RIL ne s'organise pas → précédent inexistant → préfet peut continuer à bloquer.

### M2 : Inertie culturelle/politique ✧

| Niveau | Trace | Description |
|--------|-------|-------------|
| L1 | F-LOC29 C1 | RIL perçu comme « dangereux » par maires en place (sondages AMF 2023) |
| L2 | F-LOC39 L2 | La « pédagogie du RIL » n'a jamais été organisée par l'État ni les communes (audition Sénat 2019) |
| L3 | F-LOC39 L3 | Exécutifs locaux préfèrent la « concertation fermée » au RIL ouvert (Vacquant 2024) |
| L4 | tocqueville héritage | Cause racine : culture jacobin centralisatrice ⇒ verticalité exécutive ⇒ réfraction à horizontalité référendaire |

**Boucle M2** : maire craint → RIL inactif → pas de précédent → inertie culturelle renforcée.

### M3 : Verrou médiatique ✧

| Niveau | Trace | Description |
|--------|-------|-------------|
| L1 | F-LOC31 E1 | Acrimed 2024 : référendums locaux rarement couverts presse nationale |
| L2 | F-LOC40 L2 | Presse locale couvre consultations mais rarement de manière analytique (IFOP 2023) |
| L3 | F-LOC40 L3 | RIC absent des éditoriaux → RIL l'est plus encore (cf. P3 #8 MEDIA-RIC) |
| L4 | Arcom 2024 / P3 #8 | Cause racine : concentration capitalistique média (P3 #8 MEDIA) ⇒ RIL n'est pas sujet « vendeurs » |

**Boucle M3** : médias ne couvrent pas RIL → citoyens non informés → RIL non demandé.

### M4 : Omission doctrinale (Vandenberghe) ✧

| Niveau | Trace | Description |
|--------|-------|-------------|
| L1 | F-LOC30 D3 / F-LOC41 L1 | Rapport Vandenberghe 2018 propose RIC mais ne recommande pas développement du RIL (assemblée-nationale.fr) |
| L2 | F-LOC31 E2 / F-LOC41 L2 | Doctrinalement, RIL vu comme « gadget » par les V°-Républicains purs (Vacquant 2024) |
| L3 | F-LOC31 E3 / F-LOC41 L3 | Pas de courant doctrinal « pro-RIL » structurant (Vacquant 2024) |

**Boucle M4** : doctrine ne recommande pas RIL → pas d'enseignement étudiant → pas d'imprégnation institutionnelle → RIL reste inconnu.

**Tissage** : 4 mécanismes convergent sur même verrou. M1 + M2 verrouillent organisation ; M3 verrou visibilité ; M4 verrou éducation. Score couverture ≥90% (consolidé sur 23 ans).

## 7. Verbatim et citations

### 7.1 Verbatim thèse centrale (§0)

> « Le RIC français est verrouillé par l'absence d'un chaînon institutionnel manquant entre le référendum d'initiative locale (art. L1112-1 CGCT, art. 72-1 al. 2 Constitution) et le référendum d'initiative citoyenne national (art. 11 et suivants). Ce chaînon, ouvert en droit depuis la loi constitutionnelle du 28 mars 2003 (loi Raffarin), dort dans la pratique. »

### 7.2 Verbatim F-LOC15 sur Suisse

> « La Suisse a copié le modèle suisse dans le texte, mais ne l'a pas acclimaté dans la pratique » (§13 sur France vs Suisse).

### 7.3 Verbatim §7.5 verdict

> « Le RIL est ouvert en droit mais fermée en pratique. Le verrou culturel vaut tous les autres verrous : informer les maires et les préfets n'est pas suffisant, il faut aussi informer les habitants. La majorité des maires sont sceptiques sur le RIL ; rare sont ceux qui osent l'activer. »

### 7.4 Verbatim §6 verdict « qui meurt »

> « Le verrouillage actuel est physiologique (manque d'oxygène) plutôt que mécanique (manque de structure). L'architecture institutionnelle existe, mais l'oxygène politique pour l'activer est absent. »

### 7.5 Verbatim §12 HYDRA syndromique

> « P3 #9 REFER-LOC ouvre un angle opérationnel concret : le RIL est juridique, connu et activable. C'est précisément l'angle mort que les enquêtes précédentes avaient omis. »
