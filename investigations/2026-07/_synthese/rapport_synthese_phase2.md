## 2. Thèses cardinales

### T1 : L'Oligopole généralisé

**Énoncé** : La quasi-totalité des secteurs stratégiques français sont dominés par 3 à 6 acteurs qui se partagent les marchés publics, les concessions et les subventions dans une architecture d'oligopole protégé par l'État.

**Étendue** : 14/69 secteurs (20,3 %). +1 secteur : PORN-001 (Aylo/MindGeek oligopole Pornhub, YouPorn, RedTube = ~80 % du marché occidental, captation ECP 2020).

**Solidité** (shadow) : `score = (55×1 - 2×0.2 - 5×0.5 - 0×1) / 62 = 52.1/62 = 0.84` → **TRÈS HAUTE**

**Niveau de confiance** : ⭐⭐⭐⭐ (4/5). T1 reste TRÈS HAUTE (0.83→0.84). PORN-001 ajoute l'oligopole culturel-sexuel à la cartographie : Aylo (MindGeek transformé) + OnlyFans (Radvinsky) = duopole effectif sur l'industrie pornographique mondiale. Solidité en hausse.

**Pourquoi** : 14 secteurs avec M-## oligopole/monopole documentés. PORN-001 confirme que même l'industrie du plaisir est verrouillée par 2-3 acteurs (Aylo ~80 %, Dorcel ~3 % marginal, Bel Ami marginal). Convergence intersectorielle forte : nourriture +10 Md€ Nestlé, Danone, Coca-Cola, McDonald's (NOUR) → oligopole alimentaire.

**Pourquoi pas** : Certains secteurs (startups, éditeurs-logiciels) restent fragmentés. PORN-001 documente un oligopole international, pas strictement français : nuance la souveraineté du verrou.

**Réfutation possible** : « L'oligopole pornographique est mondial, pas une capture française. » → Réponse : PORN-001 documente aussi l'impunité française (Loi 2021 vérification d'âge bloquée, Arcom moyens contraints). Le verrouillage est hexagonal.

**Niveau de confiance** : ⭐⭐⭐⭐ (4/5). T3 reste le cluster le plus dense du corpus. Capture n'est plus un phénomène sectoriel : c'est une infrastructure transversale documentée dans près d'un tiers des secteurs (32 %).

Les 4 nouveaux secteurs (Nutri-Score UE bloqué, ANSM BZD, Arcom porno, Viginum peur) confirment le pattern : les régulateurs ont les mandats mais pas les moyens ou la volonté politique.

**Réfutation possible** : « Les agences sont indépendantes. » → Réponse : Mandat sans budget, expertise captive, portes tournantes : le trio de la capture. L'ANSM a alerté sur les BZD en 2025 après 30 ans de prescriptions excessives : trop tard pour les 9 millions de patients déjà dépendants.
