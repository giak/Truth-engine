### M1 (CAU-001) : Cotisations >0 sur travail → coût employeur > salaire net

- **Niveau** : L1 (cause immédiate, ENABLER) [L227-L228](mesuré)
- **Mécanisme** : Cotisations sociales patronales (22-42 % brut) + salariales (~22 % net) → coin total ~47 % → coût employeur 87 k€ pour 60 k€ brut → salarié reçoit 46,8 k€ net [CLM-001:L142]
- **Preuves** : SRC-013 (L'Expert-Comptable, « 25 %-42 % »), SRC-014 (Dougs, « 22-42 % »)
- **Type de verrou** : Structurel — Code de la sécurité sociale, barèmes URSSAF [CTRL-001:L260]
- **Gap** : Aucun

### M2 (CAU-002) : Abonnement IA = conso intermédiaire → zéro cotisation

- **Niveau** : L1 (cause immédiate, ENABLER) [L228-L229](mesuré)
- **Mécanisme** : Achat service logiciel (API, SaaS) = consommation intermédiaire en comptabilité → hors champ cotisations sociales → seul l'IS (~25 % sur bénéfices) et potentiellement la TVA s'appliquent
- **Preuves** : CGPS, Code général des impôts (implicite — absence de cotisation sur les achats logiciels)
- **Type de verrou** : Légal — classification comptable (achat vs salaire)
- **Gap** : L'absence de cotisation sur les achats logiciels est un état de fait, pas une décision explicite « anti-IA » [L229](mesuré)

### M3 (CAU-003) : Écart coût humain vs IA → incitation économique à substituer

- **Niveau** : L2 (mécanisme intermédiaire, CAUSE) [L229-L230](mesuré)
- **Mécanisme** : Coût salarié cadre 87 k€/an vs abonnement IA pro ~2,4-4,8 k€/an → écart facteur 18-36 → incitation économique à remplacer ou ne pas recruter → érosion par non-remplacements (pas par licenciements visibles) [LED-011:L112]
- **Preuves** : Calcul arithmétique (écart coût) ; corroboration partielle : Capgemini 2 400 postes supprimés janvier 2026 (unique cas documenté France) ; ECB (avril 2026) : « muted impact » ; Anthropic (mars 2026) : « no systematic increase in unemployment » [citation §7]
- **Type de verrou** : Économique — signal-prix
- **Gap** : L'ampleur réelle dépend aussi de la productivité relative, complémentarité, et coûts de transition ; pas de données empiriques France [L230](mesuré)

### M4 (CAU-004) : Substitution → baisse masse salariale → baisse recettes cotisations

- **Niveau** : L2 (mécanisme intermédiaire, CAUSE) [L230-L231](mesuré)

- **Preuves** : Mécanisme comptable — pas de données empiriques sur l'ampleur en France [L231](mesuré)
- **Type de verrou** : Systémique — dépendance de l'assiette salariale
- **Gap** : Pas de données empiriques sur l'ampleur en France ; GAP-001 (HIGH) : aucune donnée empirique sur l'ampleur réelle de la substitution IA→travail [L368-L369](mesuré)
