## Workflow

```text
PRIMARY|CASE: BACKLOG -> READY -> TE_ACTIVE -> TE_DONE -> [RENARD if material] -> CLOSED
SYNTHESIS:    BACKLOG + DEPENDENCIES_DONE -> synthesis-card -> synthesis/review -> CLOSED
```

`SYNTHESIS` never enters `READY` or `TE_ACTIVE`; it consumes only closed dependency outputs.

Other states: `BLOCKED | CONDITIONAL | DEFERRED | MERGED | DROPPED | PILOT_REVIEW`.
Baby-step invariant: **at most one READY or TE_ACTIVE item**.

After each run: Truth Engine artifacts -> concise RUN_HANDOFF -> registry patch -> one
material TRACELOG line -> regenerate dashboard.

## Commands

```bash
python3 control.py validate
python3 control.py dashboard
python3 control.py run-card INV-XXX --output runs/INV-XXX_RUN_CARD.md
python3 control.py synthesis-card INV-XXX --output runs/INV-XXX_SYNTHESIS_CARD.md
```

The run-card command refuses non-READY or non-runnable entries. The synthesis-card command requires `type=SYNTHESIS`, `status=BACKLOG`, `gate=DEPENDENCIES_DONE`, and all direct dependencies `CLOSED`.
