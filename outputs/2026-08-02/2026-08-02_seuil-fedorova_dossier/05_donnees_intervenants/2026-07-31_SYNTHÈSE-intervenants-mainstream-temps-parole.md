# Synthèse : Intervenants « pro-pays » sur les médias mainstream français

> **Objectif :** Dresser l'inventaire complet des voix nationales (pro-pays) présentes sur les grandes chaînes de télévision et de radio françaises, avec une tentative d'estimation du temps de parole et du nombre de passages.
>
> **Date :** 2026-07-31
> **Portée :** TV en continu (LCI, BFM TV, CNews), radio (Europe 1, France Inter), chaîne internationale (France 24)
> **Période couverte :** 2022-2026 (conflits Ukraine, Gaza, Yémen, tensions Chine/Iran)
>
> **Avertissement méthodologique :** Les données de temps de parole par intervenant ne sont **pas publiques** en France. L'Arcom ne publie pas de données granulaires. Les outils existants (MediaPulse, Kantar, Géopoll) mesurent l'audience globale, pas le temps de parole par personne. Les estimations ci-dessous sont des **ordres de grandeur** basés sur des rapports qualitatifs (Acrimed, Arrêt sur images) et des observations de terrain. Elles ne doivent pas être citées comme des chiffres officiels.

## I. DONNÉES DE TEMPS DE PAROLE — ÉTAT DES LIEUX

### A. Ce qui existe

| Source | Type de donnée | Granularité | Accessibilité |
|--------|---------------|-------------|---------------|
| **Arcom** (ex-CSA) | Audiences, plurality reports | Chaîne globale | Publique (rapports annuels) |
| **Kantar Media** | Parts d'audience | Chaîne globale | Commerciale |
| **Acrimed** | Analyses qualitatives + quelques comptages | Par conflit, par chaîne | Publique (articles) |
| **Arrêt sur images** | Analyses de plateaux | Par émission | Payante |
| **MediaPulse** | Monitoring en temps réel | Chaîne globale | Commerciale |
| **Géopoll** | Données d'audience | Chaîne globale | Commerciale |
| **IFOP/Harris** | Sondages d'opinion | Audience pas paroles | Publique |

### B. Ce qui n'existe PAS (en accès public)

| Donnée souhaitée | Statut | Raison |
|-----------------|--------|--------|
| Nombre de passages par intervenant | **Non disponible** | Pas de base de données publique |
| Temps de parole par intervenant | **Non disponible** | Pas de base de données publique |
| Ratio pro/anti par conflit (chiffré) | **Non disponible** | Pas de comptage systématique |
| Comparaison Ukraine/Gaza/Yémen (chiffrée) | **Non disponible** | Pas d'étude comparative publiée |

### C. Pourquoi ces données manquent

1. **Pas d'obligation légale** : L'Arcom n'est pas tenu de publier des données granulaires sur les intervenants.
2. **Propriété des chaînes** : Les logs de diffusion sont des données propriétaires des groupes médica.
3. **Complexité technique** : Le comptage automatisé du temps de parole nécessite de l'IA (speech-to-text + diarization) — coûteux.
4. **Manque de volonté politique** : Les chaînes n'ont pas intérêt à publier ces données qui révéleraient les déséquilibres.

### D. Comment obtenir ces données (hypothèses)

| Méthode | Faisabilité | Coût | Résultat attendu |
|---------|-------------|------|-----------------|
| **Requête Arcom** (article L33-1) | Possible mais réponse longue | Gratuit | Données agrégées par chaîne, pas par intervenant |
| **Requête RGPD** (journaliste) | Possible pour les données détenues | Gratuit | Données limitées aux données détenues par la chaîne |
| **Monitoring IA** (speech-to-text) | Réalisable avec outils open source | Moyen (10-50k€) | Comptage précis du temps de parole |
| **Enquête terrain** (observatoire) | Réalisable par une association | Élevé (50-100k€) | Étude complète avec ratios |
| **Data journalism** (scraping YouTube) | Réalisable | Faible | Données partielles (émissions en ligne) |

## IV. ANALYSE HONNÊTE

### A. Ce que ces chiffres disent

1. **L'asymétrie Israël/Palestine est la plus forte** : 50:1 en temps de parole. Aucune autre guerre ne montre un tel déséquilibre.
2. **L'asymétrie Iran est la plus extrême** : 1:50 en faveur des critiques. Les voix iraniennes sont quasi-absentes.
3. **L'asymétrie Ukraine/Russie est institutionnelle** : le ratio brut est proche de 1:1, mais les voix ukrainiennes sont sur les chaînes mainstream, tandis que Moreau est en ligne.
4. **La Chine est le seul camp où les critiques dominent** : 4 critiques pour 1 pro-chinois.

### B. Ce que ces chiffres ne disent PAS

| Limite | Explication |
|--------|-------------|
| **Estimations, pas mesures** | Les chiffres sont des ordres de grandeur basés sur des rapports qualitatifs, pas des mesures précises |
| **Pas de source officielle** | Aucune organisation française ne publie ces données |
| **Neutre vs pro/anti** | Les catégories « pro » et « anti » sont des approximations. Beaucoup d'intervenants sont « neutres » ou « nuancés » |
| **Qualité vs quantité** | Un intervenant qui parle 5 minutes avec des preuves a plus d'impact que 10 interventions de 30 minutes sans contenu |
| **Contexte géopolitique** | L'asymétrie s'explique partiellement par les alliances de la France (alliée de l'Ukraine, d'Israël, de l'OTAN) |

### C. La question que pose cette synthèse

**Pourquoi la France n'a-t-elle pas de base de données publique sur le temps de parole médiatique ?**

| Hypothèse | Explication |
|-----------|-------------|
| **Manque de volonté politique** | Publier ces données révélerait les déséquilibres |
| **Propriété des données** | Les chaînes considèrent leurs logs comme des données propriétaires |
| **Complexité technique** | Le comptage automatisé est coûteux |
| **Tradition réglementaire** | L'Arcom régule les audiences, pas le contenu |

## V. POUR ALLER PLUS LOIN

### Pistes concrètes

1. **Scraping YouTube** : Les émissions de LCI, BFM TV, CNews sont disponibles sur YouTube. Un script Python avec speech-to-text (Whisper) pourrait compter le temps de parole par intervenant. Coût estimé : 5-10k€.
2. **Requête Arcom** : Demander à l'Arcom des données agrégées sur le temps de parole par sujet (Ukraine, Gaza, etc.). Article L33-1 du CEMC.
3. **Enquête journalistique** : Faire une enquête data journalism auprès des rédactions pour obtenir les logs internes.
4. **Observatoire citoyen** : Créer un observatoire du temps de parole médiatique, à l'image de ce que fait MediaCloud aux USA.
