## 1. Diagnostic éditorial

Détermine :

* la question réelle ;
* la thèse exacte ;
* les sous-thèses ;
* les présupposés ;
* les faits décisifs ;
* les maillons causaux ;
* les concepts ambigus ;
* les objections majeures ;
* les lacunes documentaires ;
* la meilleure structure narrative possible.

## 2. Trois architectures

Conçois trois architectures réellement différentes :

### Architecture A — Démonstrative

Progression fondée sur les prémisses, les preuves, les mécanismes et la conclusion.

### Architecture B — Forensique

Progression fondée sur une anomalie, une chronologie, des pièces, des contradictions et un faisceau d'indices.

### Architecture C — Narrative systémique

Progression partant d'un cas concret, remontant vers les mécanismes, puis vers les conséquences générales.

Pour chaque architecture :

* produis un plan ;
* identifie son point fort ;
* identifie ce qu'elle risque de masquer ;
* indique les données qu'elle exige ;
* formule la principale objection à son emploi.

## 3. Sélection et hybridation

Compare les trois architectures selon :

* puissance démonstrative ;
* lisibilité ;
* résistance à la contradiction ;
* fidélité aux faits ;
* tension narrative ;
* précision conceptuelle ;
* économie de moyens.

Choisis l'architecture dominante. N'hybride les autres que lorsque leur apport est indispensable.

## 4. Construction probatoire

Pour chaque affirmation importante :

* précise sa nature ;
* identifie la preuve requise ;
* distingue fait, interprétation et inférence ;
* recherche une explication concurrente ;
* calibre le niveau de certitude ;
* vérifie que la conclusion ne dépasse pas les éléments.

Ne confonds jamais :

* concomitance et causalité ;
* convergence et coordination ;
* dysfonctionnement et intention ;
* bénéficiaire et organisateur ;
* absence de document et preuve de dissimulation ;
* répétition d'une affirmation et corroboration indépendante.

## 5. Contradiction maximale

Construis la meilleure version de l'argument adverse.

Recherche notamment :

* les contre-exemples ;
* les variables omises ;
* les biais de sélection ;
* les erreurs d'échelle ;
* les glissements sémantiques ;
* les alternatives causales ;
* les faits incompatibles avec la thèse ;
* les conclusions impossibles à falsifier.

Intègre toute objection valide. Réfute précisément les objections faibles. Ne neutralise pas la thèse par prudence automatique.

## 6. Herméneutique et sémantique

Pour chaque concept structurant :

* donne une définition opératoire ;
* distingue les sens concurrents ;
* repère les connotations ;
* détecte les glissements de sens ;
* vérifie la stabilité terminologique ;
* supprime les mots-valises.

Examine aussi ce que le texte :

* affirme ;
* implique ;
* suggère ;
* présuppose ;
* laisse volontairement ou involontairement dans l'ombre.

## 7. Narration

Construis une progression perceptible :

1. entrée concrète ;
2. formulation du problème ;
3. découverte des faits ;
4. apparition du mécanisme ;
5. perturbation par une objection ;
6. résolution ou qualification ;
7. conséquences ;
8. conclusion.

Ne romance rien. N'invente ni scène, ni intention, ni dialogue. Le rythme doit provenir de la découverte et de l'articulation des faits.

## 8. Écriture

Rédige dans un français :

* soutenu mais naturel ;
* précis mais non pédant ;
* dense mais lisible ;
* ferme mais proportionné ;
* narratif sans devenir romanesque ;
* analytique sans devenir scolaire.

Supprime :

* les répétitions ;
* les transitions mécaniques ;
* les phrases génériques ;
* les abstractions inutiles ;
* les adjectifs sans fonction ;
* la grandiloquence ;
* la prudence bureaucratique ;
* les effets de manche non démontrés.

## 9. Contrôle final

Avant restitution, vérifie :

* faits ;
* dates ;
* chiffres ;
* citations ;
* chronologie ;
* causalités ;
* définitions ;
* objections ;
* cohérence ;
* proportion entre preuve et conclusion ;
* syntaxe ;
* ponctuation ;
* typographie française ;
* rythme ;
* absence de remplissage.

## Livrable

Rends :

1. le diagnostic ;
2. les trois architectures ;
3. leur comparaison ;
4. le choix argumenté ;
5. le texte final publiable ;
6. les trois vulnérabilités résiduelles ;
7. les vérifications documentaires encore nécessaires.

Ne produis pas d'itération supplémentaire lorsque les modifications restantes sont seulement cosmétiques.
