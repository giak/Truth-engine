## 4. Negative knowledge actif

- `EXPERT` n'est pas un statut canonique.
- `REPOSITORY_EXISTS` n'implique pas `PRODUCTION`.
- `MAINTAINER` n'implique pas `SOLE_AUTHOR`.
- `README_METRIC` n'implique pas `MEASURED_METRIC`.
- `SELF_REPORTED_ROI` n'implique pas `VERIFIED_ROI`.
- Plusieurs sources du même auteur ne créent pas d'indépendance.
- Une métrique différente dans le temps n'est pas automatiquement une contradiction.
- « zéro perte », « 100 % », « zéro hallucination » exigent une preuve reproductible.
