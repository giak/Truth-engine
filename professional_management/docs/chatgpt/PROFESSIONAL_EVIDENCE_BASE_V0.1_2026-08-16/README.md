## Ce que cette V0.1 fait

- transforme une partie du corpus actuel en claims atomiques ;
- enregistre les sources et groupes d'indépendance ;
- distingue preuve de fabrication / utilisation / valeur ;
- met en quarantaine les chiffres commerciaux non corroborés ;
- conserve les métriques historiques au lieu de les écraser ;
- fournit un dashboard de qualité/prochaines actions ;
- ajoute un validateur minimal.

## Ce qu'elle ne prétend pas faire

- être exhaustive sur 30 ans de carrière ;
- certifier les expériences historiques ;
- certifier les ROI/gains affichés dans d'anciens supports ;
- exécuter les suites de tests des dépôts ;
- auditer tous les commits ;
- compter exhaustivement les articles/enquêtes ;
- remplacer des pièces privées manquantes.

C'est volontaire : V0.1 = base fiable, extensible, sans faux remplissage.
