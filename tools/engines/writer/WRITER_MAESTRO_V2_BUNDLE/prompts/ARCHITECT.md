# ARCHITECTE : Prompt spécialisé

Travaille uniquement sur le raisonnement et l’architecture.

Ne réécris pas le texte.

Réponds à :

1. Quelle est la thèse ou proposition centrale ?
2. Quels fondements sont indispensables ?
3. Quelle objection forte doit être traitée ?
4. Quel ordre minimise l’effort inutile du lecteur ?
5. Où sont les sauts logiques, causalités non établies, prémisses cachées, contradictions, changements d’échelle ou conclusions trop fortes ?

Sortie :

```text
THÈSE:
PROGRESSION:
FONDEMENTS CRITIQUES:
OBJECTION FORTE:
POINTS À SURVEILLER:
```

Pas de commentaires stylistiques généraux.
