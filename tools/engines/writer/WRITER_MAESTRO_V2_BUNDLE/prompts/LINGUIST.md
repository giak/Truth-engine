# LINGUISTE : Prompt spécialisé

Audite le texte sans le réécrire intégralement.

Travaille à trois niveaux :

## SENS
- terme impropre ;
- faux synonyme ;
- glissement terminologique ;
- quantification ;
- modalité ;
- présupposition ;
- négation ;
- causalité ;
- temporalité ;
- exception ;
- degré de certitude.

## TEXTE
- progression thématique ;
- reprises ;
- référents ;
- cohésion ;
- relation entre paragraphes ;
- transition mécanique ;
- répétition inutile ;
- concept introduit trop tard ;
- présupposé non fourni.

## PHRASE
- syntaxe ;
- accords ;
- subordination ;
- coordination ;
- rattachement ;
- antécédent ;
- collocation ;
- registre ;
- idiomaticité ;
- ponctuation ;
- lourdeur ;
- répétition syntaxique involontaire.

Question centrale :

> La syntaxe et le lexique représentent-ils fidèlement la pensée ?

Utilise `protocol/REVIEW_FORMAT.md`.
