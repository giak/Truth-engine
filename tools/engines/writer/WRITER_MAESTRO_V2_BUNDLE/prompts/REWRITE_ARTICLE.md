# TÂCHE : Réécriture éditoriale complète

Applique `MAESTRO.md`.

Si `LONG_FORM.md` est chargé, applique également son protocole.

## Mission

Réécris l’article fourni pour obtenir un français :

- exact ;
- naturel ;
- précis ;
- cohérent ;
- argumentativement solide ;
- pédagogiquement clair ;
- soutenu sans raideur ;
- publiable.

## Contraintes absolues

- préserver tous les faits, chiffres, dates, citations et sources ;
- préserver le degré de certitude de chaque affirmation ;
- ne créer aucun fait, argument ou lien causal absent du matériau autorisé ;
- ne pas modifier la thèse simplement pour obtenir plus d’impact ;
- ne pas durcir une formulation prudente ;
- ne pas affaiblir une distinction importante ;
- corriger sémantique, argumentation, cohérence, progression, syntaxe, lexique et rythme lorsque nécessaire ;
- réorganiser phrases ou paragraphes uniquement si la progression y gagne réellement ;
- supprimer ou fusionner les répétitions réellement inutiles ;
- expliciter un passage elliptique uniquement à partir du matériau disponible ;
- ne pas raccourcir mécaniquement ;
- ne pas ajouter artificiellement de punchlines, fragments ou effets rhétoriques ;
- protéger les formulations déjà réussies ;
- effectuer les contrôles de non-régression avant émission.

## Règle de conservation

Ne réécris pas une phrase correcte pour le seul motif qu’une autre formulation est possible.

Toute modification doit :

1. corriger un défaut identifiable ;
ou
2. produire un gain réel sans régression.

## Ambiguïté

Si une formulation source est sémantiquement ambiguë et que le matériau ne permet pas de trancher :

- ne pas inventer ;
- conserver l’interprétation la plus prudente compatible avec le contexte ;
- si nécessaire, rendre l’ambiguïté explicite sans ajouter de fait.

## Sortie

Retourne uniquement l’article final complet, sauf demande explicite d’audit.

Aucun commentaire de méthode.

Aucune auto-évaluation.

Aucun rapport de processus.
