# GLOBAL_STATE
## Mémoire éditoriale compacte pour LONG FORM

Le GLOBAL_STATE n’est pas un résumé complet.

Il conserve uniquement ce qui doit rester stable pendant les réécritures locales.

Format :

```text
TITLE / SUBJECT:
[...]

CENTRAL_THESIS:
[...]

CARDINAL_PROPOSITIONS:
- P1:
- P2:
- P3:
[...]

ARCHITECTURE:
- Section 1 → fonction:
- Section 2 → fonction:
[...]

LOCKED_TERMS:
- terme:
  définition:
  ne pas confondre avec:

CRITICAL_FACTS:
- fait/chiffre/date:
  portée:

EPISTEMIC_CONSTRAINTS:
- proposition:
  niveau de certitude:
  formulations à ne pas durcir:

ALLOWED_CAUSAL_RELATIONS:
- A → B:
  statut:

UNESTABLISHED_RELATIONS:
- [...]

NEGATIONS / CONDITIONS / EXCEPTIONS:
- [...]

STRONG_OBJECTIONS:
- [...]

DO_NOT_REPEAT:
- [...]

PASSAGES_TO_PROTECT:
- localisation:
  raison:

OPEN_RISKS:
- [...]
```

Règles :

- compact ;
- stable ;
- factuel ;
- pas de prose décorative ;
- pas d’interprétation nouvelle ;
- mettre à jour seulement lorsqu’une décision éditoriale légitime le nécessite.
