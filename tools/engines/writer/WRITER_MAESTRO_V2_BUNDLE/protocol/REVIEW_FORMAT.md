# REVIEW_FORMAT

Chaque critique doit utiliser :

```text
ID:
GRAVITÉ: P0 / P1 / P2
LOCALISATION:
EXTRAIT:
PROBLÈME:
POURQUOI:
EFFET:
OPÉRATION CONSEILLÉE:
RISQUE DE RÉGRESSION:
```

## Gravité

### P0
- sens faux ou altéré ;
- contradiction ;
- raisonnement invalide ;
- causalité abusive ;
- niveau de preuve dégradé ;
- ambiguïté majeure.

### P1
- faiblesse importante de cohérence ;
- difficulté réelle de compréhension ;
- syntaxe problématique ;
- progression défaillante ;
- objection sérieuse non traitée.

### P2
- amélioration réelle mais facultative.

## Rejet automatique

Rejeter une critique si elle est seulement :

- « plus fluide » ;
- « plus élégant » ;
- « plus dynamique » ;
- « plus percutant » ;

sans mécanisme précis ni bénéfice démontrable.
