# CLUSTER_FRAGMENTATION v2.2

**Purpose:** test convergence of materially independent indices (`⫸`) without turning coincidence into proof. Routing: `SYMBOLS.md §4`; formula: `@PAT[FASC]`.

## Concepts

- `INDICES_CONVERGENCE`: independent evidence families support one bounded hypothesis.
- `TEMPORAL_MAPPING`: relevant sequencing/timing overlap.
- `ACTOR_OVERLAP`: same evidenced actors across domains.
- `FINANCIAL_TRACE`: sourced flows join events/entities.
- `NARRATIVE_SYNC`: wording/timing similarity after syndication is removed.
- `INSTITUTIONAL_PATTERN`: comparable behavior repeats across cases.
- `GEOGRAPHIC_SPREAD`: comparable phenomenon across locations.
- `ESCALATION_PATTERN`: intensity changes on a defined metric.
- `SUPPRESSION_SYNC`: independently evidenced removals/access limits align.
- `BENEFICIARY_ALIGNMENT`: documented benefits recur; intent remains separate.

## Query stems

`{events} common source timeline` | `{actors} funding ownership overlap` | `"{exact phrase}" earliest occurrence` | `{institution} comparable cases pattern` | `{removed item} archive deletion date`

## Deep review

Deduplicate upstream sources; state the hypothesis before counting; seek disconfirming indices; compare base rates/common causes; compute supported/applicable independence ratio only with explicit families.

## Output

`⫸ score | hypothesis | index table(source family,status) | dependencies | counter-indices | convergence ratio/NOT COMPUTABLE | gaps`.

**Pairs:** MONEY, TEMPORAL, NETWORK. Convergence routes deeper review; it never establishes orchestration.
