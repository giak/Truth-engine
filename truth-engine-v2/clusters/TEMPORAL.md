# CLUSTER_TEMPORAL v2.2

**Purpose:** reconstruct sequencing and test coordination alternatives (`⏰`). Use `@PAT[TEMP]`; `P_orch` is a diagnostic index, not probability.

## Concepts

- `TIMING_SYNC`: relevant actions occur within a defined window.
- `VOCAB_UNIFORM`: distinctive wording remains after wire/common-source deduplication.
- `CUI_BONO_TIMING`: documented preparation/benefit precedes event.
- `HISTORICAL_PATTERN`: comparable prior sequence under stated criteria.
- `SUPPRESSION_WINDOW`: evidenced removal/access change aligns with event.
- `ARTIFICIAL_URGENCY`: deadline lacks objective basis.
- `DISTRACTION_TIMING`: high-attention release overlaps material event.
- `ANNIVERSARY_MANIPULATION`: symbolic date selection is documented/relevant.
- `SILENCE_PERIOD`: unusual communication gap under a baseline.
- `NARRATIVE_SHIFT`: agenda/topic changes materially and abruptly.

## Query stems

`"{phrase}" earliest timestamp` | `{actors} announcement time press release` | `{document} archive deletion correction` | `{deadline} legal basis` | `{event} prior comparable timeline`

## Deep review/output

Normalize time zones and publication/update times; find common wire/upstream release; score only documented P_orch inputs; build and state a null model before any `P_random`, otherwise NOT ESTIMATED; seek mundane scheduling causes. Output `⏰ timeline | P_orch inputs/index | P_random/NOT ESTIMATED | common causes | coordination evidence | gaps`.
